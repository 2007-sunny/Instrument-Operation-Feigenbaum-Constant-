# 示波器 / 函數產生器 控制台

GW Instek **GDS-1072B** 示波器 + **AFG-2112** 函數產生器，透過 USB 在電腦上：

- 即時顯示 CH1 / CH2 波形，並自動算 Vpp、頻率、平均值、**CH2/CH1 增益與相位差**
- 一鍵儲存波形（CSV + PNG 截圖），CSV 可直接用 Excel / Python 開
- 設定產生器：波形、頻率（含 ×2 ÷2 ×10 ÷10 快速鍵）、振幅、偏移、輸出開關
- **自動掃頻 → 波德圖**（增益 dB、相位），並估算 −3 dB 頻率，可存 CSV + PNG
- **模擬模式**：不接儀器也能試用（模擬 CH2 接了一個截止頻率 1 kHz 的 RC 低通濾波器）

## 檔案

| 檔案 | 用途 |
|---|---|
| `app.py` | 主程式（圖形介面） |
| `start.bat` / `start_sim.bat` | 雙擊啟動 / 以模擬模式啟動 |
| `test_connection.py` | 第一次接儀器時的連線測試（只查詢，不改設定） |
| `instruments.py` | 儀器指令（SCPI）與模擬器 |
| `analysis.py` | 頻率估計、鎖相分析（振幅/相位） |
| `config.py` | 可調整的設定 |

## 第一次使用

1. **建立虛擬環境 `.venv`**（這台電腦已建好；換電腦時在本資料夾執行）：
   ```
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
   `start.bat` / `start_sim.bat` 會自動使用 `.venv`；手動執行時請用 `.venv\Scripts\python.exe`
   （例如 `.venv\Scripts\python.exe test_connection.py`）。
2. **安裝 USB 驅動**：到 GW Instek 官網下載 GDS-1000B 與 AFG-2100 系列的 USB 驅動並安裝。
   接上 USB 後，在「裝置管理員 → 連接埠 (COM 和 LPT)」應該會看到兩個 COM 埠。
3. **示波器設定**：若面板 Utility → I/O 有 USB Device 模式選項，選擇電腦連線模式。
4. **跑連線測試**：
   ```
   .venv\Scripts\python.exe test_connection.py
   ```
   會自動偵測兩台儀器、讀一次波形、比對電壓換算是否正確，結果存在 `test_log.txt`。
   如果出現 ✘，照著提示改 `config.py`，或把 `test_log.txt` 貼給 Claude 修正。
5. **啟動**：雙擊 `start.bat`，選好 COM 埠（或按「自動偵測」）→「連線」。

## 波形畫面操作（游標）

| 操作 | 方法 |
|---|---|
| 放大某一段 | 在波形上**按住左鍵拖曳框選**；滾輪可縮放 |
| 回到示波器畫面範圍 | 按「重設視圖」（或勾回「自動視圖」） |
| 時間游標 T1/T2 | 勾選後拖曳兩條直線，顯示 Δt、1/Δt 及各通道在 T1、T2 的電壓 |
| 電壓游標 V1/V2 | 勾選後拖曳兩條橫線，顯示 ΔV |
| 只看選取範圍 | 「放大到 T1~T2」；勾選「量測與存檔只用 T1~T2 之間」後，Vpp/平均/增益/相位與 CSV 都只用這段資料 |
| 定住畫面慢慢量 | 按「凍結畫面」，游標仍可拖曳 |

## 頻譜 FFT

切到「頻譜 FFT」分頁，CH1/CH2 的頻譜會即時更新，並自動標出最大的幾個峰（▼）、相對基頻的 dBc 與 THD。

| 設定 | 說明 |
|---|---|
| 視窗 | Hanning（通用）、Flat-top（**振幅最準，量諧波用這個**）、Blackman（看小訊號）、矩形 |
| 單位 | dBV（= 20·log₁₀(Vrms / 1 V)）或線性 Vrms |
| 線性 / 對數頻率 | 看寬頻範圍時用對數 |
| 補零 | 只讓曲線較平滑，**不會**提高真正的解析度 |
| 平均 N 張 | 功率平均，可壓低雜訊底線 |
| 頻率游標 | 拖曳讀出任意頻率的振幅 |

- **解析度 Δf = 1 / 畫面總時間**。要分辨更接近的頻率 → 加大時基（畫面多放幾個週期），或加大 `config.py` 的 `RECORD_LENGTH`。
- **最高頻率 = 取樣率 / 2**。時基越大，取樣率越低、能看的最高頻率越低。
- 勾選「量測與存檔只用 T1~T2 之間」時，FFT 也只算那一段。
- 示波器是 8-bit ADC，雜訊底線大約在主訊號下 40~50 dB，低於此的諧波量不到（THD 會顯示「&lt; 某值」）。

## 共振掃頻（「掃頻」分頁 → 「波德圖」）

- **方向**：往上 / 往下 / 往上再往下（檢查遲滯）。兩個方向用不同顏色畫在同一張圖，CSV 的 `direction` 欄記錄方向。中途不關輸出、不重設；細掃開始前會先把頻率移到起點外側，讓電路從正確的一側接近。
- **間隔**：對數或線性。
- **自動兩階段**：先粗掃找增益最大的點，再自動在「峰 × (1 ± x%)」線性細掃。
- **自動分析**（顯示在圖下方，也寫進 CSV 檔頭）：
  - f_res（增益峰）：峰值附近 3 點拋物線內插
  - f_res（相位過零）：增益峰附近相位由正變負的交叉點，線性內插
  - 峰值增益、−3 dB 頻寬、Q = f_res / Δf
  - C_eff = 1 / ((2π f_res)² L)，L 在「電感 L」欄輸入
- **小訊號**：可用「程式平均」（每點讀 N 次，逐點平均後再鎖相）或「示波器平均」（`:ACQuire:MODe AVERage`）。
  CH1 或 CH2 小於 0.5 格的點標為「訊號太小，不可靠」（紅色 ×，CSV 的 `unreliable` = 1）。
- **振幅檢查**：每點記錄產生器設定值（`AFG_set_Vpp`、`AFG_load`）與 CH1 實測。
  掃完取 CH1 最大振幅（遠離共振時最接近開路電壓）與設定值比較，差超過 30% 會跳出警告。
  （共振時電路阻抗很低，CH1 本來就會因產生器 50 Ω 內阻而下降，所以不是逐點比較。）
- **開始前設 AC 耦合**：C–V 量測有大 DC offset 時勾選，避免垂直刻度被 offset 拉大。

## 批次參數掃描（「批次」分頁 → 「參數掃描」）

輸入一串振幅（Vpp）或 DC offset（V），每個值自動跑一次「掃頻」分頁設定的掃描（建議開兩階段）。
- 每個值存一個 CSV，全部完成後存 `summary.csv`（參數、方向、f_res 增益峰、f_res 相位過零、峰值增益、Q、C_eff…）與 `summary.png`，放在 `data/batch_日期時間/`。
- 「沿用上一個 f_res」：下一個值的粗掃範圍 = 上一個 f_res × 下限 ~ × 上限（振幅預設 0.6 ~ 1.1；offset 預設 0.9 ~ 1.6）。

## 分岔圖（「分岔圖」分頁）

固定頻率、逐步加大振幅；每個振幅抓長紀錄（預設 1 萬點、至少 100 個週期），每個驅動週期取一個 CH2 值。
- **固定相位取樣（推薦）**：相位基準預設為 CH2 基頻波峰（自動），也可改為 CH1 驅動。
- **每週期最大值**：視窗以設定相位為中心、前後各半週期，避免視窗邊界切在波峰上造成假分岔。
- 自動判斷週期 1 / 2 / 4 / 8 / 混沌（比較第 i 與第 i+p 個值），並用鎖相算出 f/2、f/4 分量（dBc）確認。
- 存成 `bifurcation_*.csv`（每個週期的值）與 `*_summary.csv`（每個振幅的判斷結果）。

## 安全

- `config.py`：`AMPLITUDE_MAX_VPP`（預設 4 Vpp）、`PEAK_MAX_V`（|偏移|+振幅/2，預設 6 V）。超過會拒絕設定，批次掃描開始前會先檢查全部的值。
- 中途按「停止」時，產生器可選：保持輸出 / 降到最小振幅 / 關閉輸出。

## 模擬模式（`start_sim.bat`）

`config.py` 的 `SIM_MODEL = "rlc"`：產生器(50 Ω) → L → C → R_sense(10 Ω)，f0、Q 用 `SIM_RLC_F0`、`SIM_RLC_Q` 設定。
`SIM_NONLINEAR = True` 時共振頻率隨振幅（依 LTspice 預期值表）與 DC offset 改變，可用來測試批次掃描。
分岔圖模式在模擬時會自動加上倍週期行為（logistic map）。

## 示波器、產生器的新設定

- 示波器分頁：CH1/CH2 的耦合（DC / AC / GND）、探棒 ×1 / ×10、頻寬限制、擷取模式（一般 / 平均 N 次）。
- 產生器分頁：負載設定 High-Z / 50 Ω（連線時自動讀回）。
- 這些指令第一次使用前，請執行 `test_connection.py`，看查詢結果是否正常（若頻寬限制的格式不同，改 `config.py` 的 `BWLIMIT_ON/OFF`）。

## 掃頻（波德圖）接線

```
AFG 輸出 ──┬──> 待測電路輸入 ──> 電路輸出 ──> CH2
           └──────────────────────────────> CH1
```
- 示波器觸發來源設為 **CH1**
- 掃頻時程式會自動調整時基與垂直刻度；每一點會先讓示波器 STOP 再讀兩個通道，確保是同一次擷取
- 相位差定義為 φ(CH2) − φ(CH1)，低通濾波器會是負值（輸出落後）

## 常見問題

- **找不到 COM 埠**：驅動沒裝好，或 USB 線只有充電功能。
- **讀波形逾時**：確認通道有開；把 `config.py` 的 `TIMEOUT_S` 調大；`RECORD_LENGTH` 保持 1000。
- **存下的電壓和螢幕不一樣**：照 `test_connection.py` 的建議修改 `COUNTS_PER_DIV`。
- **更新率很慢**：USB 虛擬 COM 埠傳輸有限，每秒數張屬正常；只開一個通道會快一些。
- **產生器振幅和示波器量到的差兩倍**：產生器負載設定為 50 Ω 但接的是高阻抗，在產生器面板把負載改成 High-Z。

## 備註

GDS-1000B 讀波形的資料格式（標頭欄位、每格 count 數）是依官方 Programming Manual 的格式撰寫，
